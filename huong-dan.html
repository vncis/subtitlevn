Cài "AI đám mây" cho Phụ Đề Việt

Làm một lần, khoảng 10 phút, hoàn toàn miễn phí. Sau đó việc nghe và dịch lời thoại chạy trên máy chủ AI — điện thoại không còn bị thiếu bộ nhớ.

Bạn sẽ tạo 2 thứ

Thứ cần tạoĐể làm gì
Mã API Groq"Chìa khoá" để dùng AI của Groq (miễn phí): Whisper large-v3 nghe lời thoại và AI ngôn ngữ dịch phụ đề.
Trạm CloudflareTrạm trung chuyển nhỏ giữ chìa khoá giúp bạn. Cần có vì Groq không cho trang web gọi thẳng, và để chìa khoá không bị lộ trên trang.
Nên làm phần A và B trên máy tính (dễ sao chép, dán code). Phần C làm trên điện thoại.

ATạo mã API Groq

Khoảng 2 phút

  1. Mở console.groq.com → đăng ký / đăng nhập (bằng Google hoặc email).
  2. Ở menu bên trái chọn API Keys (hoặc mở thẳng console.groq.com/keys).
  3. Bấm Create API Key → đặt tên, ví dụ phude-viet → bấm tạo.
  4. Sao chép mã ngay (thường bắt đầu bằng gsk_) và dán tạm vào Ghi chú. Groq chỉ hiện mã này một lần; nếu lỡ mất thì xoá và tạo mã mới.

Không chia sẻ mã này cho ai. Ở các bước sau bạn chỉ dán nó vào Cloudflare.

BTạo trạm Cloudflare

Khoảng 6–8 phút

  1. Mở dash.cloudflare.com → đăng ký tài khoản miễn phí (xác nhận email nếu được hỏi).
  2. Ở menu trái chọn Workers & Pages (có thể nằm trong mục Compute) → bấm Create application → chọn Create Worker / mẫu Hello World.
  3. Đặt tên Worker là phude-viet → bấm Deploy. Cloudflare tạo cho bạn một địa chỉ dạng
    https://phude-viet.<tên-tài-khoản>.workers.dev
  4. Bấm Edit code. Xoá hết code mẫu bên trái, rồi dán toàn bộ code ở khung dưới (bấm nút "Sao chép code") → bấm Deploy.
  5. Quay lại trang của Worker → Settings → mục Variables and Secrets → Add, thêm lần lượt 3 dòng:
    TypeVariable nameValue
    SecretGROQ_API_KEYmã Groq ở bước A (gsk_…)
    SecretACCESS_CODEmột mật khẩu bạn tự đặt, ví dụ PhuDe2026!
    TextALLOWED_ORIGINhttps://vncis.github.io
    Rồi bấm Deploy để lưu.
  6. Mở địa chỉ trạm trên trình duyệt. Nếu thấy dòng "Tram Phu De Viet dang chay" là trạm đã hoạt động.
ALLOWED_ORIGIN phải đúng địa chỉ trang web của bạn: bắt đầu bằng https://, không có dấu / và tên thư mục ở cuối. Nếu ứng dụng nằm ở https://vncis.github.io/phude-viet/ thì vẫn chỉ điền https://vncis.github.io.

Code của trạm (file cloudflare-worker.js):

// =====================================================================
//  TRẠM TRUNG CHUYỂN "PHỤ ĐỀ VIỆT"  →  Groq Whisper (AI nghe lời thoại)
//  Dán toàn bộ file này vào Cloudflare Worker (xem file huong-dan.html).
//
//  Biến môi trường cần đặt trong Cloudflare (Settings → Variables and Secrets):
//    GROQ_API_KEY   (Secret, bắt buộc)  — mã API lấy ở console.groq.com
//    ACCESS_CODE    (Secret, nên có)    — mật khẩu tự đặt; nhập vào ứng dụng
//    ALLOWED_ORIGIN (Text, nên có)      — địa chỉ trang web được phép dùng trạm,
//                                         ví dụ: https://vncis.github.io
//
//  Trạm chỉ chuyển tiếp nguyên vẹn yêu cầu lên Groq (không đọc, không lưu),
//  thêm mã API vào, rồi trả kết quả về ứng dụng.
//    ?task=transcribe → nghe & chép lời (Whisper)
//    ?task=translate  → nghe & dịch lời nói sang tiếng Anh (Whisper)
//    ?task=chat       → dịch phụ đề sang ngôn ngữ đã chọn (AI ngôn ngữ)
//  Phiên bản trạm: 2
// =====================================================================

const GROQ = 'https://api.groq.com/openai/v1/';
const ENDPOINTS = { transcribe: 'audio/transcriptions', translate: 'audio/translations', chat: 'chat/completions' };
const MAX_BYTES = 25 * 1024 * 1024; // giới hạn file của gói miễn phí Groq

export default {
  async fetch(request, env) {
    const origin = request.headers.get('Origin') || '';
    const allowed = String(env.ALLOWED_ORIGIN || '*')
      .split(',').map(s => s.trim().replace(/\/+$/, '')).filter(Boolean);
    const originOK = allowed.includes('*') || (origin && allowed.includes(origin));

    const cors = {
      'Access-Control-Allow-Origin': originOK ? (origin || '*') : 'null',
      'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type, X-Access-Code',
      'Access-Control-Expose-Headers': 'Retry-After',
      'Access-Control-Max-Age': '86400',
      'Vary': 'Origin',
    };
    const json = (obj, status = 200, extra = {}) =>
      new Response(JSON.stringify(obj), {
        status,
        headers: { ...cors, 'Content-Type': 'application/json; charset=utf-8', ...extra },
      });

    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: cors });

    // Mở địa chỉ trạm bằng trình duyệt → chỉ báo trạm đang chạy (không lộ gì)
    if (request.method === 'GET' && !origin) {
      return new Response('Tram Phu De Viet dang chay. Hay dung ung dung de ket noi.', {
        headers: { 'Content-Type': 'text/plain; charset=utf-8' },
      });
    }

    if (!originOK) return json({ error: { message: 'Trang web này không được phép dùng trạm (kiểm tra ALLOWED_ORIGIN).' } }, 403);
    if (env.ACCESS_CODE && request.headers.get('X-Access-Code') !== env.ACCESS_CODE) {
      return json({ error: { message: 'Sai mã truy cập.' } }, 401);
    }
    if (!env.GROQ_API_KEY) return json({ error: { message: 'Trạm chưa có GROQ_API_KEY.' } }, 500);

    // Ứng dụng bấm "Kiểm tra kết nối"
    if (request.method === 'GET') return json({ ok: true, service: 'phude-viet', version: 2 });
    if (request.method !== 'POST') return json({ error: { message: 'Method not allowed' } }, 405);

    const url = new URL(request.url);
    const task = ENDPOINTS[url.searchParams.get('task')] || ENDPOINTS.transcribe;
    const len = Number(request.headers.get('Content-Length') || 0);
    if (len > MAX_BYTES + 1024 * 1024) return json({ error: { message: 'File âm thanh quá lớn (tối đa 25 MB).' } }, 413);

    // Chuyển tiếp nguyên vẹn (không phân tích file → nhanh, không tốn CPU của trạm)
    const upstream = await fetch(GROQ + task, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${env.GROQ_API_KEY}`,
        'Content-Type': request.headers.get('Content-Type') || 'application/octet-stream',
      },
      body: request.body,
    });

    const headers = {
      ...cors,
      'Content-Type': upstream.headers.get('Content-Type') || 'application/json; charset=utf-8',
    };
    const ra = upstream.headers.get('retry-after');
    if (ra) headers['Retry-After'] = ra;
    return new Response(upstream.body, { status: upstream.status, headers });
  },
};

CKết nối ứng dụng trên điện thoại

1 phút, làm trên từng điện thoại / máy tính muốn dùng

  1. Mở ứng dụng Phụ Đề Việt → mở mục "AI đám mây cho điện thoại".
  2. Dán địa chỉ trạm (https://phude-viet.….workers.dev) và nhập mã truy cập (ACCESS_CODE).
  3. Bấm Kiểm tra kết nối → thấy ✓ Kết nối tốt là xong. Ô "Dùng AI đám mây" sẽ tự bật.
  4. Từ giờ chọn video và bấm Tạo phụ đề như bình thường. Ứng dụng nhớ cài đặt, lần sau không cần nhập lại.

Cập nhật code trạm (khi có bản mới)

  1. Vào Cloudflare → Workers & Pages → bấm vào phude-viet → Edit code.
  2. Xoá hết code cũ, dán code mới ở phần B (nút "Sao chép code") → bấm Deploy.
  3. Không cần thêm lại 3 biến GROQ_API_KEY / ACCESS_CODE / ALLOWED_ORIGIN — chúng vẫn được giữ.
  4. Trong ứng dụng bấm Kiểm tra kết nối: thấy "✓ Kết nối tốt! … (nghe + dịch)" là đã dùng code mới.

Nếu gặp lỗi

Ứng dụng báoCách sửa
Không kết nối được tới trạmKiểm tra lại địa chỉ trạm (phải bắt đầu bằng https:// và đúng chính tả), và mạng internet.
Sai mã truy cậpMã nhập trong ứng dụng phải giống hệt ACCESS_CODE (phân biệt chữ hoa/thường).
Trạm từ chối trang web nàySửa ALLOWED_ORIGIN cho đúng địa chỉ trang (xem lưu ý ở phần B), rồi bấm Deploy.
Mã API Groq trong trạm không đúngTạo mã mới ở Groq, sửa lại GROQ_API_KEY trong Cloudflare, rồi Deploy.
Trạm đang dùng code cũLàm theo mục "Cập nhật code trạm" ở trên.
Dịch vụ đang giới hạn lượt dùngGói miễn phí giới hạn số giờ âm thanh mỗi giờ/ngày. Ứng dụng tự chờ rồi gửi tiếp; nếu vẫn báo, thử lại sau.

Cần biết

  • Chi phí: miễn phí trong giới hạn. Groq miễn phí hiện cho khoảng vài giờ âm thanh mỗi ngày (xem con số chính xác ở trang giới hạn của bạn); Cloudflare miễn phí 100.000 lượt gọi mỗi ngày.
  • Dung lượng mạng: mỗi phút video gửi lên khoảng 2 MB âm thanh (video 20 phút ≈ 40 MB). Nên dùng Wi-Fi.
  • Riêng tư: chỉ âm thanh và lời thoại được gửi lên Groq để nghe và dịch; hình ảnh và việc lồng chữ vẫn làm trên máy của bạn. Trạm không lưu lại gì.
  • Muốn chạy hoàn toàn trên máy như trước: tắt ô "Dùng AI đám mây" trong ứng dụng.
